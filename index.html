0.3.1 正式版 2026.11.25

联机页重做

  • IPv6 直连（新）：无需第三方服务器。房主建房发邀请码，房客填入后回传确认码， 游戏里填生成的代理地址。需双方都有公网 IPv6。
  • 陶瓦联机（旧）：IPv6 不通时可在「其他方式」里选用。

修复与优化

  • 依赖误报：Forge 可选项（mandatory = false）被误认为必需前置，误报大幅减少。
  • GPU 不显示：主页性能卡的 GPU 占用一直为空，已修。
  • 启动卡顿：硬件查询改后台执行，阻塞从 1.04 秒降至 0.026 秒。
  • 界面不换页：联机页点「陶瓦联机」时右半侧不刷新，已修。

注意

  • 单文件版首次启动解压至 %TEMP%\.net\，报错时可手动清理该目录。
  • 上游整合包更新尚未做全量验证。
0.3.0 正式版 2026.11.16

底座重建

  • 整个项目改为在 PCL_Plus 4.0.1 源码上继续开发，不再往老 exe 里注入代码。
  • 换底座之后可以用上 .NET 10 的 WPF 特性，之前卡住的液态玻璃有了实现条件。
  • 自绘 M 图标，标题栏显示 PCL_Max 文字。

修复

  • 反馈 / 软件信息 / 查看日志 / 管理四页点开即报「未知的设置子页面种类」，已全部恢复。
  • 检查更新一直失败——更新源指向了不存在的仓库，仓库名还写成了下划线。
  • 主页性能条 CPU 跑满时只走到三分之一，改为按进度槽真实宽度换算。
  • WebP 明明系统支持却提示缺失，改为检查系统解码器与 libwebp.dll。
发布公告模板（写群公告时照这个套）

结构固定五段：下载 / 功能 / 修复 / 升级注意 / 反馈。
下载段官网与直链都给——两者都可能被网络环境影响，多给一条路。
修复效果用定性描述（「误报大幅减少」），不抛内部测试数字，省得被追问剩下的部分。
已知问题压成一句带过。总字数控制在 600 以内（QQ 群公告硬限制）。
